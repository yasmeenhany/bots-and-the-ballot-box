# TwitBot-20 Data

Follow the instructions in the [TwitBot-20](https://github.com/BunsenFeng/TwiBot-20) repository to download the dataset.

Extract `TwiBot-20-Format22.zip` and copy `node.json`, `edge.csv`, `label.csv` and `split.csv` in this directory.

Run `preprocess.py` in the `twibot_20` folder to process the dataset. The processed files (e.g. `cat_properties_tensor.pt`, `label.pt`) will be in the `twibot_20/processed_data` folder.
